## 🌐 Компоненты

- [Слайдер Swipper](./swiper-responsive/index.html) — Адаптивный Swiper-слайдер с карточками товаров, кастомной навигацией и разным количеством слайдов на разных разрешениях экрана.
- [Tabs + Swiper](./tabs-filter-swiper/index.html) — фильтрация слайдов через tabs. Сырой код. Надо смотреть.
- [Swiper с обрезаными слайдами](./swiper-with-middle-slide/index.html) — Слайдер swipper где по бокам обрезаны слайды.
- [Любимые шрифты](./favorite-fonts.html) — Любимые шрифты
- [Оптимизация изображений](./image-making-smaller.html) — Оптимизируем изображения чтобы они весили меньше.
- [Центрирование элемента в CSS Grid](logo-in-center.html) — Используем grid-template-columns: 1fr auto 1fr, чтобы центральный элемент всегда находился ровно по центру. Левая и правая колонки имеют одинаковую ширину, даже если их содержимое отличается по размеру.
- [Навигационное меню - 01](./navigation-01/index.html) — Мое навигационное меню
- [Навигационное меню - 02](./navigation-02/index.html) — Мое навигационное меню где ссылки по центру, а кнопки сбоку. А потому они идут в мобильное меню. Хитрость тут в margin: 0 auto; у nav.
- [Бесконечный скролл](./infinite-horizontal-scroll-animation/index.html) — Двигаются иконки медленное.
- [Грид шпаргалка](./grid-cheatsheet/index.html) — Грид шпаргалка
- [Любимый код бургер меню](./burger-menu-code-best.js) — Лучшее бургер меню для меня. код js
